# Snake

A classic Snake game in a single `index.html` — no build step, no dependencies beyond two web fonts (the game falls back to system fonts offline).

- Cozy garden look: cream page, wood-framed grass field, a round little snake that sways as it slides, and seven kinds of crop to nibble
- Leaf bursts and gentle plucked notes when you eat; a low note when the run ends
- Works on phone, tablet, and desktop
- Keyboard (arrows / WASD), swipe, or on-screen D-pad; pause and settings buttons in the header
- Settings: pace (Cozy / Normal / Brisk), sound, garden details, reduce motion — saved locally
- Hitting a wall or yourself ends the game
- Best score is saved locally
- Reduce motion defaults to the OS preference and can be overridden in Settings

Open `index.html` in a browser to play.
